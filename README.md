## 共通する所見

2本の調査を通じて、同じ構造が繰り返し現れた。

- **ユーザーは集まるが金にならない領域が多い。** Speechify はユーザー5,000万人で ARR 約$17.6M、Wattpad は月間9,000万MAU で6億ドル買収後に2.57億ドル減損。
- **「まだ誰もやっていない」と見えるものの多くは、既に試されて失敗している。** なろうの発掘ランキングは公式実装済みで形骸化、記事読み上げは OS 標準機能に内蔵済み。
- **プラットフォームを新規に立てる道はほぼ塞がっている。** 勝てた事例はすべて、出版・IP・既存ユーザーベースなど別の強みを先に持っていた。
- **決め手は市場データより「自分がそれを本当に必要としているか」。** この領域は市場からの報酬で走り続けることが期待できないため、燃料が個人的な必要性しかない。

## 調査上の共通制約

いずれの調査も、実行環境の egress プロキシにより WebFetch がほぼ全ドメインで遮断されており、
一次資料の原本確認ができていない。数値は検索結果の要約に依拠しているため、
意思決定に用いる前に各レポート末尾の「調査の限界」を参照のうえ、出典元での再確認を推奨する。

法務に言及した箇所はいずれも調査メモであり、法的助言ではない。
