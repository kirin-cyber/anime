# 元写真からの実測

モデルの比率はすべてこの実測から決めている。写真は 592 × 1280 px。

## 測り方

目視では誤差が大きいので、輝度のエッジ画像に対して行方向・列方向のプロファイルを取り、
ピーク位置を境界として読んだ（`FINGERBOARD` の縦棒を含む列帯、プレート左右端を含む行帯）。

## 読み取った位置（写真の px）

| 位置 | px |
|---|---|
| プレート上端（前面） | y = 448 |
| 1 行目 キャップ上端 | y = 462 |
| 1 行目 ベースライン | y = 545 |
| 1 行目のプレート下端 | y = 562 |
| 2 行目 キャップ上端 | y = 558 |
| 2 行目 ベースライン | y = 645 |
| プレート下端 | y = 660 |
| プレート左端 / 右端 | x = 33 / 567 |
| `F` の左端 | x = 48 |
| 支柱の幅 | 50 px |
| プレート下端 → 台座上面 | 130 px |
| 台座の幅 | 140 px |

## 導かれる比率

| 項目 | px | 字高比 |
|---|---|---|
| プレート | 534 × 212 | アスペクト 2.519 |
| 1 行目 字高 | 83 | 1.000 |
| 2 行目 字高 | 87 | 1.048 |
| 行間（1 行目ベースライン→2 行目キャップ上端） | 13 | 0.157 |
| 文字とプレート外周の余白 | 15 | 0.181 |
| `FINGERBOARD` の文字幅合計 | 504 | 6.072 |

2 行目が 1 行目より約 5% 大きい。これを見落としてキャップ高を共通にすると
プレートのアスペクトが 2.67 前後になり、写真と合わなくなる（`CAP2_SCALE` を入れた理由）。

## 絶対寸法

写真に寸法の基準物が写っていないため、**プレート全幅を 80 mm と仮定**して
上の比率から他をすべて決めている。実物の寸法が分かっている場合は
`src/build.py` の `TARGET_WIDTH` だけを変えれば全体が追従する。

結果として得られた寸法:

| 部位 | 寸法 |
|---|---|
| プレート | 80.0 × 31.6 mm |
| 1 行目 字高 / 2 行目 字高 | 12.3 mm / 13.0 mm |
| 行間 | 1.9 mm |
| 文字まわりの余白 | 2.2 mm |
| 支柱 | 幅 7.5 mm、台座上面から 20 mm |
| 台座 | 20 mm 角 + 19 mm 角 |
| 全体 | W 80.0 × D 20.0 × H 57.5 mm |

板厚（3 mm）とレリーフの深さ（1.2 mm）、彫り線の深さ（0.5 mm）は正面写真からは
測れないため、合板サインの一般的な値を置いている。

## 位置合わせによる検証

`src/texture.py` はモデルの輪郭（プレート外形＋文字）を写真のエッジ画像に重ね、
一致度が最大になる射影変換を探索する。その結果を重ねた画像が
[`out/alignment-check.png`](../out/alignment-check.png)。

一致度スコアは比率を直す前が 0.226、直した後が 0.275。
